# Mental Health in Tech: Predicting Treatment Seeking Behavior
This projects explores factors influencing mental health treatment-seeking behavior among tech employees using a simple logistic regression model.

## Key Steps
- Data cleaning and feature engineering (Pandas)
- Eploratory data visualization and analysis (Matplotlib, Seaborn)
- Predictive modelling (Logistic Regression)
- Model evaluation using ROC_AUC

## Tools Used
Python | Pandas | Numpy | Scikit-learn | Matplolib | Seaborn

## Results
The model achieved an accuracy of 0.69 and an AUC of 0.73.
